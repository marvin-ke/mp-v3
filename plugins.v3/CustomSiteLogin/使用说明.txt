自定义网站自动登录 v1.5.6 · 脱敏分享包

一、功能及范围
支持色花堂登录/签到、Chiphell 每日登录奖励、颠影普通/幸运签到和每日转盘。
不包含 NodeSeek。支持统一通知、按站点时间调度、账户核验和异常提交防重复。
验证码识别不保证成功，遇到网站的 CF/人机验证或风控时，可能需要手动处理。
颠影转盘逐次执行，最多 20 次；当前每次 5 积分、最多消耗 100 积分。

二、适用环境
实际验证环境：Linux Docker、MoviePilot 3.2.6、Python 3.14。
源码使用 MP v3 的 runtime.settings、foundation.crypto 和统一消息接口。
不承诺兼容 MP v2、旧版 v3、Windows 直接运行或非同架构容器。
本包是插件源码和运行准备工具，不是可直接启动的独立应用。

三、安装插件
推荐按 MP 自定义插件仓库方式安装：
1. 在自己的 GitHub 插件仓库根目录放置 package.v3.json，合并已有索引时仅添加 CustomSiteLogin 条目。
2. 将 plugins.v3/customsitelogin 整个目录放到仓库的对应位置。
3. 在 MP 的插件市场添加自己的仓库地址，然后安装“自定义网站自动登录”。
4. 刚安装时保持总开关关闭，不要先导入其他人的配置。
若只在容器里复制目录，未必会自动注册到 MP，请优先使用插件市场安装。
本包不会替你发布仓库，也不包含任何已配置好的私人仓库 URL。

四、准备运行依赖和模型
将整个分享包解压到 MP 的 /config/share-customsitelogin 下。
宿主机实际路径取决于你自己的 /config 映射，容器名也使用你自己的。
在宿主机运行（把 <MP容器名> 替换成实际名称）：

docker exec -w /app <MP容器名> python /config/share-customsitelogin/setup_runtime.py

上面仅预览。确认路径后执行：

docker exec -w /app <MP容器名> python /config/share-customsitelogin/setup_runtime.py --apply --install-deps

此工具只创建缺失的空白私有配置、复制校验过的模型、按需安装依赖；
不覆盖已有私有配置，不启用自动任务，不提交签到或发通知。
依赖版本记录自实际部署，其他架构或 Python 版本若无法安装，需自行适配。
浏览器组件首次使用可能仍需联网下载及可用的 Linux 系统库。

五、绑定自己的账号
编辑容器内 /config/custom-site-login/sources.json：
把 sites 中对应站点的 expected_uid 从字符串 "0" 改成自己的数字 UID。
仅需配置准备启用的站点；未使用站点保留 "0"，不要选中。
mac 字段是历史兼容字段名，表示可选的第二套 CookieCloud 来源，留空即可。
主要来源自动读取 MP 系统的 CookieCloud KEY 和端对端密码。
不要把编辑后的 sources.json 上传到 GitHub 或重新发给别人。
config/plugin.example.json 是禁用状态的参考模板，不含真实账号。

六、启用与核验
1. 开启 MP 本地 CookieCloud 服务；在自己的浏览器登录所需网站并手动同步。
2. 修改 UID 后重新加载插件，让绑定生效。
3. 配置页选择需要的站点，按需开启色花堂签到、颠影转盘、普通/幸运签到。
4. 代理沿用 MP 系统设置；默认色花堂、颠影启用，Chiphell 直连。
5. 通知使用 MP 已启用且接收“站点”消息的渠道。需要通知时再打开插件通知开关。
6. 确认 Cookie、UID、依赖与网络正确后，打开总开关并保存。
7. 在分站点记录里核对账户、奖励、余额和执行时间，不能仅凭“已登录”判断奖励到账。

默认执行时间（北京时间）：颠影 09:17/21:17，Chiphell 09:37/21:37，色花堂 09:43/21:43。
已经确认完成的当日任务会跳过；失败重试受各站点上限和冷却规则约束。

七、包含/排除内容
包含：12 个插件 Python 文件、公开站点地址、识别模型、空白模板、依赖版本和说明。
排除：真实 Cookie、API Key、CookieCloud KEY/密码、UID 绑定、私人 IP/域名、
MP 配置数据库、sources.json、浏览器个人目录、历史日志、截图、通知记录、检查点和备份。
所有任务模板默认关闭；分享包不会继承导出者的自动签到任务。
源码已将个人电脑来源名称改为通用名称，并允许只配置 MP 主来源。

八、版本说明
本包基于线上 v1.5.6。色花堂登录未通过时每 10 分钟检查登录态，不占每日 5 轮签到额度。
颠影实际签到/转盘和通知在导出前的线上部署已验证；朋友的新环境仍需自行核验。
分享版单独调整了来源文案与可选备用来源逻辑，已完成编译和脱敏检查。
